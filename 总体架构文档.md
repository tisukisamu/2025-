# 街舞工作室管理系统 - 总体架构文档

## 1. 系统概述

### 1.1 项目背景
街舞工作室管理系统是一个面向舞蹈培训机构的管理平台，旨在提供课程管理、学员管理、教师管理、财务管理等全方位的信息化解决方案。

### 1.2 系统目标
- 提高工作室运营效率
- 简化学员报名流程
- 优化课程排班管理
- 实现财务透明化
- 提供数据分析和决策支持

### 1.3 技术选型

#### 前端技术栈
- **框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **UI组件库**: Ant Design Vue
- **CSS框架**: UnoCSS
- **状态管理**: Pinia
- **路由**: Vue Router
- **HTTP客户端**: Axios

#### 后端技术栈
- **框架**: Spring Boot 2.7+
- **ORM**: Hibernate / Spring Data JPA
- **数据库**: MySQL 8.0+
- **认证授权**: Spring Security + JWT
- **构建工具**: Maven
- **开发语言**: Java 11+

#### 文件存储
- 本地文件系统
- 存储路径: `upload/`
- 数据库存储: 相对路径

### 5.2 服务器配置

#### 开发环境
- 前端: `localhost:5173` (Vite Dev Server)
- 后端: `localhost:8080` (Spring Boot)
- 数据库: `localhost:3306` (MySQL)

#### 生产环境
- 前端: Nginx静态文件服务
- 后端: Spring Boot JAR包运行
- 数据库: MySQL独立服务

### 5.3 Nginx配置示例

```nginx

    listen 80;
    server_name example.com;

    # 前端静态文件
    location / {
        root /var/www/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # API代理
    location /api/ {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 文件上传大小限制
    client_max_body_size 10M;
}
```
