# 招聘管理系统总体结构设计

## 1. 系统概述

招聘管理系统是一个面向求职者和企业的综合性招聘服务平台，采用前后端分离架构，支持三类用户角色：

- **求职者端**：用户注册登录、职位搜索、简历管理、投递申请、面试管理、消息通知
- **企业端**：企业入驻、职位发布、简历筛选、面试安排、人才库管理、评价反馈
- **管理端**：用户管理、企业审核、职位监管、公告发布、投诉处理、数据统计

## 5. 接口设计规范

### 5.1 RESTful API 规范

- 基础路径：`/api`
- 认证方式：JWT Token (Bearer Token)
- 请求格式：JSON
- 响应格式：JSON

### 5.2 统一响应结构

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

### 5.3 状态码规范

| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未授权/Token失效 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 6. 权限设计

### 6.1 角色定义

| 角色 | 说明 | 权限范围 |
|------|------|----------|
| USER | 普通用户/求职者 | 简历管理、职位投递、消息查看 |
| COMPANY | 企业用户 | 企业管理、职位发布、简历筛选、面试安排 |
| ADMIN | 系统管理员 | 用户管理、企业审核、系统配置、数据统计 |

### 6.2 权限控制

- 前端：路由守卫 + 角色判断
- 后端：Spring Security + @PreAuthorize

## 9. 设计原则

1. **安全性**：JWT认证、权限控制、数据校验
2. **可扩展性**：模块化设计、接口统一规范
3. **可维护性**：代码分层清晰、注释完善
4. **用户体验**：响应式设计、友好提示、操作便捷
5. **性能优化**：分页查询、缓存策略、懒加载
