## 3. 安全与权限

### 3.1 认证方式

- 登录成功返回JWT Token
- 前端请求头携带：`Authorization: Bearer <token>`
- 后端通过 `JwtAuthenticationFilter` 解析并注入用户上下文

### 3.2 授权规则

| 路径 | 权限 |
|------|------|
| `/api/auth/**` | 公开 |
| `/api/jobs` (GET) | 公开 |
| `/api/companies` (GET) | 公开 |
| `/api/announcements` (GET) | 公开 |
| `/uploads/**` | 公开（静态资源） |
| `/api/admin/**` | ADMIN角色 |
| 其他接口 | 需登录 |

### 3.3 角色枚举

```java
public enum Role {
    USER,      // 普通用户/求职者
    COMPANY,   // 企业用户
    ADMIN      // 管理员
}
```

### 3.4 用户状态枚举

```java
public enum Status {
    ACTIVE,    // 正常
    DISABLED   // 禁用
}
```

## 4. 配置说明

### 4.1 数据库配置

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/recruitment_system
    username: root
    password: your_password
    driver-class-name: com.mysql.cj.jdbc.Driver
  jpa:
    hibernate:
      ddl-auto: update
    show-sql: true
```

### 4.2 JWT配置

```yaml
jwt:
  secret: your-jwt-secret-key
  expiration: 86400000  # 24小时
```

### 4.3 文件上传配置

```yaml
file:
  upload-dir: upload/
```

### 4.4 静态资源映射

- URL路径：`/uploads/**`
- 本地目录：`file:upload/`

## 9. 业务规则

1. **投递限制**：同一职位不可重复投递
2. **企业审核**：企业需审核通过后才能发布职位
3. **权限校验**：企业操作需验证企业状态
4. **文件存储**：文件保存到本地 `upload/` 目录，数据库存储相对路径
5. **密码加密**：使用 BCrypt 加密存储
6. **Token过期**：默认24小时
